# ARIA

Repositorio del asistente / agente de IA **ARIA**.

> **Pendiente de definir:** el significado de la sigla, el propósito, el alcance
> y los usuarios de ARIA. Todavía no están documentados. Complételos en
> `docs/vision.md` antes de cargar contenido.

## Estructura

| Carpeta | Contenido |
| :--- | :--- |
| `prompts/` | Prompts de sistema y plantillas de instrucciones, versionados |
| `knowledge/` | Base de conocimiento que consulta el agente (documentos fuente) |
| `skills/` | Skills o capacidades específicas del agente |
| `evaluaciones/` | Casos de prueba y criterios para validar las respuestas del agente |
| `docs/` | Documentación del proyecto: visión, alcance, decisiones |
| `.claude/skills/` | Skills de proyecto para Claude Code (viajan con el repositorio) |

Cada carpeta tiene un `README.md` que describe qué debe contener.
