# tableros/

Tableros de control generados por ARIA, organizados por año y con
nombre de archivo `tablero-al-<dd-mm-aaaa>.md`, según la fecha de corte
de la Matriz de Seguimiento que los originó.

Cada tablero sigue el formato de salida de
`../prompts/prompt-sistema.md`: (1) tablero de estado por semáforo de
los cinco módulos, (2) alertas priorizadas, (3) vacíos de información
declarados, (4) plan de acción sugerido, sujeto a validación del
Auditor Interno.

Los tableros se conservan como histórico — no se sobrescriben al
generar uno nuevo.
