# knowledge/

ARIA no almacena aquí los documentos fuente. Esta carpeta es el mapa de
correspondencia entre cada módulo de control de ARIA y su fuente real,
en el repositorio `raraya2607-creator/Gobernanza-de-la-IA`.

| Módulo de ARIA | Fuente en `Gobernanza-de-la-IA` | Skill que la mantiene |
| :--- | :--- | :--- |
| 1. Seguimiento de Recomendaciones | `docs/06-matriz-seguimiento/` | `seguimiento-recomendaciones-auditoria` |
| 2. Planes Anuales de Trabajo (PAT) | `docs/04-plan-anual-trabajo/<año>/` | `incorporar-documento-gobernanza-mivah` |
| 3. Cubo de Riesgos | `docs/02-cubo-riesgos/` | `cubo-riesgos-mivah` |
| 4. Control de Auditorías del Año | `docs/04-plan-anual-trabajo/<año>/` cruzado con `docs/05-informes-auditoria/<año>/` | `incorporar-documento-gobernanza-mivah` |
| 5. Códigos de Buena Gobernanza | `docs/03-codigos-gobernanza/` | `incorporar-documento-gobernanza-mivah` |
| 6. Plan Estratégico e Indicadores Anuales de Objetivos Estratégicos | `docs/01-plan-estrategico-2025-2030/` | `incorporar-documento-gobernanza-mivah` |

Antes de trabajar sobre cualquier módulo, ARIA confirma que
`Gobernanza-de-la-IA` está adjunto a la sesión y lee su `CLAUDE.md`.

Detalle completo de cada módulo (qué controla, cuándo alerta, vacíos ya
declarados) en `../prompts/prompt-sistema.md`.
